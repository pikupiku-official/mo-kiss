# イベント用体験版

2026-10-16。Python起動用の体験版ロジック。通常版と同じタイトル・ウィンドウ・設定・dialogueを利用し、進行は `demo/flow.py` が管理する。
KS本文・演出は人間が `events/GDxxx.ks` で編集する。

## 起動

プロジェクトルートで：

```powershell
.\.venv-gd\Scripts\python.exe demo/demo.py
```

必要な依存関係が入ったPythonなら `python demo/demo.py` でもよい。
絶対パスで指定すれば別の作業ディレクトリからも起動できる。
ウィンドウ・仮想画面・フルスクリーン切替は `main.py` と同じ初期化を使う。
PVの音声準備にはPATH上の `ffmpeg` が必要。映像は既存MovieManager（OpenCV、利用不可時はFFmpeg）を使用する。

動画は以下へ配置する：

```text
movies/PV3min.mp4
movies/PV1min.mp4
```

動画未配置・音声準備失敗時は黒背景にエラーと復帰操作を表示する。ESCでタイトルに戻れる。

- 選択①②の映像はいずれも `PV3min.mp4`。視聴後はタイトルへ戻る。
- 全PVはESCでスキップ可能。右下に操作を表示。スキップ後もタイトルへ戻る。
- タイトルで20秒操作がなければ `PV3min.mp4` を再生する。
- 放置PVではキー・マウス移動・クリック等の操作で即座にタイトルへ戻る。復帰操作ではOPを開始しない。
- タイトルで操作するたび、設定を閉じたとき、PVから戻ったときに放置時間を数え直す。
- PVは縦横比を維持して全体表示し、余白は黒。BGM・SEを止め、動画の音声を再生する。
- PV音声は初回に非同期でPCMへ変換し、アプリ終了まで一時キャッシュする。準備中もキャンセル可能。
- HOMEの日記・翌朝・登校演出は省略。「寝る」で選択②へ進む。ベッドの「戻る」は有効。
- KSが空、またはコメント・ラベルだけの場合は本文を生成せず次へ進む。存在しないKSはエラー画面にする。
- GD001の「桃子が誘いを渋る理由」は、デモの実行データで結果分岐の直前に入力待ちを補う。確認済みKS原稿は編集せず、原稿に入力タグが追加された場合も二重に表示しない。
- 日時は専用フローが設定し、通常イベント一覧の日時とは独立して表示する。

## 操作・状態

- 主人公名：久保田 航輝。試遊開始ごとに設定。
- 会話の操作は次のとおり。自由入力中は文字編集を優先する。

| キー | 通常の会話 | 自由入力中 |
| --- | --- | --- |
| Enter / テンキーEnter | 文章を即表示、表示済みなら次へ。長押し・同一フレームの連打は進行を予約しない | 回答送信。IME変換中は変換確定 |
| Esc | 設定を開く／閉じる。バックログより優先 | 設定を開く／閉じる |
| B | バックログを開く／閉じる | 文字入力。バックログはCtrl+B |
| A | AUTO切替 | 文字入力 |
| Space | 文章スキップ切替 | 文字入力 |
| T | 文章表示切替 | 文字入力 |
| ↑ / ↓ / PageUp / PageDown | バックログ表示中のスクロール | カーソル移動。バックログ表示中はスクロール |
| F8 | デバッグ表示切替 | モデル状態・判定スコアを確認（IME変換中はIMEを優先） |
| F11 | フルスクリーン切替 | フルスクリーン切替 |

- セーブ／ロード・タネ一覧・通常版MAP／HOMEへのショートカットは提供しない。
- 画面構築前にローディングを表示し、読み込み中の入力は次画面に持ち越さない。
- `GD005.ks`の`MOMOKO_TP1`は同梱のRuriモデルによる意味判定を使い、画面構築時にバックグラウンドで読み込む。自由入力ではAUTO・スキップを停止する。
- A／Spaceと画面ボタンによるAUTO／SKIP切替は、キャラ・CGの演出中も受け付ける。有効なボタンは枠で表示する。演出そのものは終了まで再生する。
- SKIPでは段落を最初から全文表示し、句読点・文字送りの待ち時間を省略する。自由入力・選択肢では進行を止め、会話末尾では通常の次画面へ進む。
- 通常の文字送りは経過時間で追いつく。同じ文字・日付・天気の縁取りやピクセル加工は最大512件まで再利用し、フォント・色・効果が変わったときは描き直す。
- 専用の画面選択は矢印キー＋Enter／Space、またはクリック。
- F11によるフルスクリーン切替は通常版と共通。
- 進行・名前・タネ・ストーリーフラグ・会話状態は、一時プロファイルに分離する。
- 試遊開始ごとにタネとストーリーフラグを初期化する。本編の `data/current_state/` と `events/story_flags.json` は使用しない。
- 音量・表示等の設定は通常版の `data/settings.json` と共有する。
- 通常版の起動経路で環境変数 `MOKISS_PROFILE_ROOT` が未指定なら、保存先は従来どおり。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| demo.py | 一時プロファイル・参照パス・Qtの準備と起動 |
| application.py | 既存GameApplicationのウィンドウを使う体験版アプリ |
| flow.py | ステージ順・KS名・日時・放置時間 |
| screens.py | 黒背景の選択と入力処理 |
| GDmap.py | 暫定の教室1項目MAP |
| GDhome.py | 既存HOMEの画像・移動演出と体験版の操作制限 |
| movie.py | 音声付きPV・スキップ・放置PVのキャンセル |

共有側では `core/path_utils.py` のプロファイル対応を通じて、名前・時間・タネ・会話状態・保存マネージャー・KSローダーの状態保存先を切り替える。

## 検証

```powershell
.\.venv-gd\Scripts\python.exe -m pytest tests/test_demo_flow.py -q -p no:cacheprovider
.\.venv-gd\Scripts\python.exe tests/demo_smoke_runner.py
.\.venv-gd\Scripts\python.exe tests/demo_playback_runner.py
```

- 専用テストで画面順・日時・実入力での選択制限・保存先分離を確認。
- FFmpeg使用可能な環境では、音付きの短い検証用動画を生成し、音声再生・黒帯・自然終了・操作キャンセルを確認する。
- スモークテストは実KSの読み込み・描画と終了通知による画面間の受け渡しを確認する。全文を通読する再生テストではない。
- スモークテストで、本編進行ファイル・GD系KSのハッシュが実行前後で一致することを確認。
- `demo_playback_runner.py`は実時間・実入力でGD001をSKIP再生し、入力待ち・誤答からの再入力・実モデル判定・正解会話・次画面への遷移を確認する。入力画面・正解画面と計測結果は `outputs/demo-playback/` に生成する。
- 画面画像は `outputs/demo-smoke/` に生成。
- 本番PV2本の再生、実スピーカーでの聴取、日本語IMEの手操作は未検証。
