# Repository guidance

## KS expression drafts

- When asked to create or revise an expression AI draft in `events/*.ks`, use the `$expression-draft` skill.
- Treat only KS files marked `;@expression-status: human_confirmed` as reviewed examples.
- Never modify a `human_confirmed` target.
- Expression-draft work is limited to expression-related `chara_show` and `chara_shift` attributes. Do not change dialogue, backgrounds, BGM, SE, branches, event control, placement, or unrelated formatting.
