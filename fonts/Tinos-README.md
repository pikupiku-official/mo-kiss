# Tinos Regular

Tinos was used by the initial English dialogue implementation. Since 2026-10-20,
English dialogue uses the existing bundled `MPLUSRounded1c-Medium.ttf` instead.
The files and provenance below are retained for the original font.

- Upstream: https://github.com/googlefonts/tinos
- Font source: https://raw.githubusercontent.com/googlefonts/tinos/main/fonts/ttf/Tinos-Regular.ttf
- License source: https://raw.githubusercontent.com/googlefonts/tinos/main/OFL.txt
- Retrieved: 2026-10-19
- License: SIL Open Font License 1.1, included as `Tinos-OFL.txt`.
- Font SHA256: `60a0e8ef0c04dd5dd69ffe91025fa2ae5836cbd35600a82ba031977557e2cb61`

`Tinos-Regular.ttf` is distributed unmodified. Existing Japanese and mixed
dialogue continues to use the existing M PLUS 1p font.
